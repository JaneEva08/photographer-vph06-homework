# Photographer website and mini-CRM — VPh06

Учебный проект: сайт фотографа и мини-CRM для зарубежных заказчиков. В репозитории находятся исходный код, конфигурация Docker Compose, отчёт по заданию, скриншоты desktop- и mobile-версий сайта на трёх языках и в двух темах, формы заявки и проверенных функций.

## Структура

- `vph06-photographer-crm/backend` — API и работа с PostgreSQL.
- `vph06-photographer-crm/frontend` — публичный сайт и административный интерфейс.
- `vph06-photographer-crm/nginx` — конфигурация веб-сервера.
- `vph06-photographer-crm/compose*.yaml` — конфигурации сервисов и вариантов запуска.
- `VPh06-HOMEWORK.md` — отчёт по критериям задания со скриншотами.

## Безопасность

Реальные `.env`, ключи, пароли, сервисный аккаунт Google и данные сервера в репозиторий не включены. Для локального запуска создайте собственный `.env` на основе `.env.example`, создайте секреты скриптами и проверьте Compose-конфигурацию. Не используйте демонстрационные значения на публичном сервере.

## Стек

Python, FastAPI, PostgreSQL, JavaScript, Docker Compose, Nginx, Google Sheets API (настраивается отдельными приватными секретами).
